# 教师端使用说明

浏览器打开就能用。不用装东西。

---

## 一、进门

### 注册

1. 打开 `https://mythclass.ryokuryuneko.top`
2. 右上角点「注册」
3. 用户名 3-32 位，中英文都行
4. 密码至少 6 位
5. 提交完直接进控制台

如果管理员把注册关了，注册页会显示「注册已关闭」。找管理员要账号。

### 登录

登录页有进度条，会依次显示三件事：

```
正在登录…
正在连接服务器…
正在寻找客户端…
```

超过 10 秒会多一句「请耐心等待」。这不是卡死，是网络在磨。

---

## 二、首页

首页兼官网介绍。从上往下：

1. **Hero**：产品名 + 「不推门，也能巡课」
2. **今日一言**：每天一句，点「换一句」可以往下翻
3. **功能特性**：看屏幕、能控制、听声音、留痕迹、多人用、发命令
4. **部署架构**：四段路，全靠出站
5. **常见问题**：六个常被问到的
6. **页脚**：GitHub、文档、版本号、隐私政策

导航栏右侧有个月亮/太阳，点一下换主题。主题记在本地。

---

## 三、绑定一台一体机

第一次用，列表是空的。

1. 去教室里那台一体机，托盘图标**左键单击**，弹出「关于」
2. 抄下「机器 ID」，形如 `MYTH-3F2A-9C21-B4D8`
3. 回控制台，左边点「绑定」
4. 填 ID，起个名字（比如「高一(3)班一体机」）
5. 提交

绑定成功后左边列表里就有它了。绿点表示在线。

一台机器只能被一个账号绑。绑错了去 Admin 后台改归属。

---

## 四、控制台

左边是机器列表，右边是工作区。工作区五个页签：屏幕、音频、文件记录、命令、设置。

### 屏幕

| 按钮 | 干什么 |
|---|---|
| 开始看 | 让客户端开始推画面 |
| 停止 | 停了它，省一体机的性能 |
| 远程控制 | 打开后你的鼠标键盘会作用过去 |
| 截图 | 存一张当前画面 |
| 全屏 | 画面铺满屏幕 |
| 缩放 | 0.4x 到 2x 拉滑块 |

画面下方有一行小字：`1280×720 · 12 fps`，那是分辨率和实际帧率。

**远程控制要小心。** 打开后你在画面上点一下，一体机上就真的点一下。

退出这个页签会自动停流，不用手动关。

### 音频

上面一块「现在在放什么」：进程名、窗口标题、音量条。

下面一张历史表：时间、进程、标题、音量、状态。

状态有 `playing`、`muted`、`idle`。`idle`（音量 0 又没静音）的压根不上报，所以没噪音。

音频空着有两种可能：真没人放，或者一体机没装 `pycaw`。

### 文件记录

谁动过文件都在这。列：时间（精确到秒）、操作、文件路径、大小。

上面能搜路径、按操作筛选（新建/修改/删除/移动/重命名）。

三个按钮：

- **导出 CSV**：把当前这一页导出来（带 BOM，Excel 打开不乱码）
- **清空**：删掉这台机器在服务端的全部记录，问一次才动手
- 翻页

记录条数上限在「设置」页里改，双端同步。

### 命令

十个格子，点一下发一条：

| 命令 | 效果 |
|---|---|
| 锁屏 | 立刻锁 |
| 解锁 | 只能提示人手动解（Windows 不让程序代解） |
| 关机 / 重启 / 注销 | 会再问一次 |
| 弹消息 | 一体机弹窗，一分钟没人点自己关 |
| 开网页 | 用默认浏览器打开 |
| 开程序 | 起一个进程 |
| 发文件 | 从 URL 下个文件放到指定路径 |
| 屏幕广播 | 一体机全屏显示广播页，Esc 退出 |
| 禁止上网 | 加防火墙规则（要管理员权限） |

命令下面有「执行回执」，成功是绿的，失败是红的。

发出去了不等于执行成功——网络那一跳只保证「送到了」。

### 设置

**记录保留策略**：最多多少条、最多占多少字节。改完点保存，服务端存一份、那台机器也立刻改。

**服务器**：显示官方服务器地址和当前教师端地址。官方那条永远在，删不掉。

**危险操作**：解绑这台机器、退出登录。

## 五、改名与解绑

工作区右上角：

- **改名**：随时改，列表里立刻变
- **解绑**：解了就看不见它了。机器本身还在线上，去 Admin 后台能找回来

---

## 六、每日一言与加载提示

### 每日一言

首页那块按日期取，同一天进来是同一条。点「换一句」往下翻，纯本地 JSON（`src/data/quotes.json`），想加自己往里写。

### 加载提示

登录、注册、连接都走一个进度遮罩，显示百分比和当前步骤。超过 10 秒会多一句「请耐心等待」。

步骤是真实阶段，不是动画凑数。

## 七、主题

导航栏右侧的月亮/太阳图标。

- 深色：苔绿底，晚上不刺眼
- 浅色：米白底，白天更清楚

存在浏览器本地，换设备不跟随。

---

## 八、账号设置

导航栏右上角头像点开：

- 控制台
- 账号设置（也是进控制台）
- 退出登录

**改密码**走接口 `POST /api/auth/change-password`。改完所有旧登录状态立刻失效——别的设备会被踢下线，得重新登。

---

## 九、常见问题

| 问题 | 原因 |
|---|---|
| 列表是空的 | 还没绑定。去机器上抄 ID |
| 在线状态一直灰的 | 机器离线，或者它连的是别的服务器 |
| 点开始看没反应 | 检查 EdgeOne 的 WebSocket 开关开了没 |
| 画面每 5 分钟断一次 | EdgeOne 300 秒超时。会自动重连，不用管 |
| 命令显示已发送但机器没动 | 看「执行回执」，或者机器那台的服务权限不够 |
| 登录后马上被踢 | 账号被封了，或者密码在别处改过 |
| 注册页说注册关了 | 让管理员在 Admin 后台打开 |
