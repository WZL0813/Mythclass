# 局域网直连与信任记录

## 一句话

一体机和老师端每次登录都上报自己的地址；服务端发现两边同一个出口 IP
就判定「同一个局域网」，画面走两端直连、不占服务端带宽；
同一个 IP 的老师端直连满 3 次，一体机把它记成信任并发一张配对密钥，
以后拿这张密钥可以不经服务端直接控制。

## 三件事分开讲

### 1. 记地址

- **一体机**：`identity.local_ips()` 取本机内网 IPv4（出口网卡 + 主机名解析），
  注册和每次心跳都带上，服务端存进 `clients.local_ips`。
- **老师端**：浏览器不告诉页面自己的内网 IP（WebRTC 之外没有正经 API，
  现在浏览器还会用 mDNS 藏起来），所以**老师那边的地址由服务端从
  `CF-Connecting-IP` / `X-Forwarded-For` 里取**。

### 2. 判「同一个局域网」

服务端比较两边的**出口 IP**：

```
老师出口 IP  203.0.113.9
一体机出口 IP 203.0.113.9   →  sameNetwork = true
```

教室里的一体机和老师的笔记本通常走同一个学校出口，出口 IP 一样就基本
可以认定在同一个局域网。这不是 100% 准确（同一个学校出口下的两个不同
网段也会被判成一样），但它只是一个**提示和优先策略**，
真正能不能直连由两端自己试出来（P2P 通了就是直连）。

被判定为同一局域网时，教师端工具栏会出现「同一局域网」小标记。

### 3. 开端口 + 信任记录

一体机常驻监听一个 TCP 端口（默认 `26924`，配置项 `lanPort`），
协议是一行一个 JSON：

```
→ {"type":"hello","key":"<配对密钥>","name":"老师的机器"}
← {"type":"hello","ok":true,"port":26924}
→ {"type":"ping"}
← {"type":"pong","t":1758700000000}
→ {"type":"command","command":"lock","args":{}}
← {"type":"result","command":"lock","ok":true,"output":"锁了"}
```

密钥怎么来：老师端每次直连（服务端认证过的 offer）记一次，
**同一个 IP 满 3 次**就生成一张 32 位十六进制的密钥存进
`%APPDATA%\Mythclass\trusted-teachers.json`，并写进日志。

**为什么是「IP + 密钥」而不是光看 IP**：教室里谁都能把 IP 改成老师那台
机器的地址。只认 IP 的话，随便一台机器都能控制一体机。
密钥是第一次（那时还有服务端认证）才发得出来的，别人拿不到。

`MythclassClient.exe --status` 能看到当前状态：

```
局域网端口：开着（26924，已服务 12 条命令）
信任的教师端：192.168.31.111（已信任）；192.168.31.112（1/3 次）
```

## 本地网页：老师直接打开就能控制

一体机自己起了一个小网页（默认 **26925** 端口），老师跟它在同一个局域网时，
浏览器直接打开 `http://<一体机的内网IP>:26925/` 就能看画面、下命令，
**完全不经过服务器**。

页面上有：机器名与归属（就是「拉取服务器用户和绑定信息」那一步拿到的）、
实时画面、常用操作按钮（锁屏/解锁/关机/重启/注销/发消息）。

**为什么用 http 不用 https**：教师端页面是 https，浏览器不许它连 `ws://`
（混合内容，静默失败）。但「点链接跳到另一个页面」是允许的 ——
老师从教师端点一下打开这个 http 页面，它自己就是 http 源，
跟同源接口说话没有任何混合内容问题，也不需要证书。
浏览器会标「不安全」：这条路上确实是明文，前提是你信这个局域网。

### 两条放行路径

| 情况 | 怎么进 |
|---|---|
| **同一个 IP 直连满 3 次** | 直接进，连密钥都不用填（主人定的规则） |
| 换了台电脑（IP 变了） | 贴一次配对密钥，浏览器记住，以后免填 |

密钥跨 IP 通用：`trust.check_any()` 会看它是不是任何一台被信任机器发出来的。

被信任的 IP 列表和密钥在 `%APPDATA%\Mythclass\trusted-teachers.json`，
`MythclassClient.exe --status` 里也能看到。

## 教师端：「是否切换至直连」

一体机和老师出口 IP 一样时，教师端工具栏会出现「同一局域网」标记和
「走直连」按钮。点它（或者点「开始看」时）会弹一个确认框：

```
要不要切到直连？
「高一(3)班一体机」和你在同一个局域网。
切到直连就是打开它自己开的页面，画面直接来自它，不经过服务器。
                                    [切到直连]  [继续走服务器]
```

选「切到直连」就新开标签页打开那台机器的本地网页。

## 还有两处没做

1. **客户端界面里查看绑定信息**：现在只在 `--status` 和本地网页上能看到，
   客户端窗口/托盘还没做专门的展示。
2. **本地网页的 HTTPS 版**：http 页面在浏览器里会被标「不安全」。
   要消掉得给一体机配自签证书，代价是老师那边要先点一次证书例外。

## 相关文件

| 文件 | 干什么 |
|---|---|
| `Mythclass-Client/mythclass/identity.py` | `local_ips()` 取本机内网地址 |
| `Mythclass-Client/mythclass/trust.py` | 信任记录、配对密钥、`check_any()` |
| `Mythclass-Client/mythclass/lanport.py` | 局域网直连端口（TCP + 一行一个 JSON） |
| `Mythclass-Client/mythclass/lanweb.py` | 本地网页（HTTP 页面 + 抓帧 + 下命令） |
| `Mythclass-Client/mythclass/bindings.py` | 拉取并缓存「本机绑定了哪些老师」 |
| `Mythclass-Client/mythclass/__main__.py` | 收到 offer 记一次；起停端口与网页 |
| `Mythclass/server/src/routes/client.js` | 存 `local_ips`；`GET /teachers` 给客户端拉绑定 |
| `Mythclass/server/src/routes/auth.js` | 算 `sameNetwork`、返回 `myIp` |
| `Mythclass/server/src/sockets/index.js` | 把老师真实 IP 标在 `from.ip` |
| `Mythclass/teacher/src/views/DashboardView.vue` | 同局域网标记 + 「走直连」提示框 |
